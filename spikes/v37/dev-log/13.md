"exampleOnly", C1/C3 included); with a "weakest sentence" field it misses X-12/P2-22 and flags 10/15 positives.
A narrow "states the idea / example only" check is blind (P2-20 "statesIdea" in both orders). A pairwise link
check is biased to the last-listed label; order consensus looked like it isolated P2-22.

**Changes:** (1) in D, agreement of the independent check outranks lexical heuristics (V3–V7) and the row's
self-reported confidence (V10); V2, V9, V11 still bind — measured: when both readers say correct, a heuristic
downgrade was a true positive in 12/12 run-instances; (2) conditional order-consensus link check before
mastery; (3) the leak closed: an unmatched reason clause is an unsettled reason; (4) independent facets
(claim state per family, reasoning state, misconceptions) on every outcome.

## Result (three fresh real-model runs)

Harness-only part (re-scored dev12 runs): mastery recall 59 → 72%, commit accuracy 88.1 → 90.4%, follow-up
58.1 → 54.7%. Full dev13: canonical 5/5 ×3, commit accuracy 89–92%, but false mastery 3/58 in two runs.
**The link check is pure position bias in the pipeline**: all nine links answered "doesNotShow" in one order
and "shows" in the other (P2-22 and X-12 included), so no link was ever unsound. Worse, the agreement rule
overrode V3 on P2-22's "Because it is encrypted" mapped to "not automatically encrypted" (dev14 fixes this).
