# dev02 — capability probes, and the reader's vocabulary

Not a full iteration: direct probes of what the on-device model can tell apart, on P's gold (open),
through a throwaway probe tool (arbitrary instructions and schema; scratch only). Then one C run with
the changed reader (`readings/C-mac-dev02.jsonl`).

| Probe (P, 80) | Framing | Coarse | Note |
|---|---|---|---|
| W1 | whole answer, a restatement then a 6-way verdict | 31/80 | restatement did not help |
| W2 | whole answer, 6-way verdict | 39/80 | right vs not-right is 70/80; the kind of wrong collapses into `wrongReason` |
| W3/W4 | yes/no "anything false?" | 30/80, 28/80 | yes to almost everything |
| W5–W7 | defined labels with a shared prefix | 34, 44, 25 | `accurate…` prefixes pool probability; reversing the order flips the answers |
| **W8** | **whole answer: correct · vague · mistaken · flawedReason, defined** | **58/80** | ~0.5 s; misconception 21/28 |
| W9 | the same as letters | 48/80 | |
| R1/R2 | segment rows, new words | 37, 32 | rows follow the claim list by position ("1 → c1 correct") |
| S1 | one call per segment | 39/80 | over-fires "mistaken" |
| S2 | rows with a gist first | 48/80 | gist anchors rows to content |

**Findings that shaped V37:** (1) label wording decides what this model can express: short everyday
words with distinct first tokens, each defined; (2) the whole-answer judgement is its strongest signal;
(3) multi-row labelling is position-driven, not content-driven.

**Change:** relation spelled `correct · vague · mistaken · unrelated` on the wire (mapped back to the
contract), a gist field first, the prompt rewritten with definitions; the pairwise second opinion
replaced by the W8 whole-answer check, run concurrently. On C the check was right on all five cases;
the rows still called C2 and C4's copying reason `correct`.
