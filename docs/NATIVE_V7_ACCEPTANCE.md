# Native V7 opening acceptance

V7 is based on V6. PDF import persistence and horizontal reader paging remain unchanged.

The launch experience now has a deterministic cinematic duration of approximately 5.6 seconds on a normal cold launch:

1. 0–0.56s: dark library hold.
2. 0.56–1.61s: warm light reveal.
3. 1.61–2.66s: scene settles and mascot blink/glasses glint occurs.
4. 2.66–3.81s: deliberate hero hold so the artwork can be appreciated.
5. 3.81–4.73s: dark-green/book-toned handoff into the real library.
6. Library fades in over 0.92s.

There is no synthetic page rectangle, spinner, progress overlay, or blocking network work.
Reduced Motion uses a static, shorter handoff.
