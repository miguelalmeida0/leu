# Shelf Native V10 acceptance

V10 is a stabilization patch.

- Opening experience is disabled entirely; Shelf launches directly to the library.
- Reader top chrome has one clean hierarchy with no overlapping segmented control.
- Horizontal page changes are available in both Read and Original modes.
- Original PDF mode uses a pan recognizer rather than speed-sensitive swipe recognizers.
- Bottom previous/next buttons remain the deterministic fallback.
- Existing PDF import, study marks, text sizing, speech, and local persistence from V9 are preserved.
