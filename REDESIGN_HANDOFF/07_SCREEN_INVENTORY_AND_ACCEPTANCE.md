# LEU — REDESIGN SCREEN INVENTORY & ACCEPTANCE

Claude should redesign a system, not one hero screen.

## Required primary screens / states

### Library

- default library with continue reading;
- search/filter state;
- book actions;
- empty/first-import state;
- local-storage/privacy cues only where useful.

### Reader

- Original PDF mode;
- Read Mode;
- Contents;
- search;
- marked passage / learning-action entry;
- voice transport;
- source return from a learning surface;
- dark/light reading appearance where supported.

### Explain Like I'm 10

- Standard result;
- Even simpler;
- Show an example with visible **Illustration** treatment;
- original passage disclosure;
- unavailable/refused/failed state that does not feel catastrophic;
- return to same source/page.

### Understanding Lens

- normal passage-specific Lens;
- progressive disclosure for relationships/related content;
- direct source action;
- future Lens 2.0 sections accommodated without card soup.

### Study landing

- topic/scope/time entry;
- due/fading/weak concepts without dashboard clutter;
- Active Recall / Interview / Progress / Reconstruction access.

### Study activity types

Design separate but coherent states for:

- MCQ;
- open recall;
- confidence choice;
- source reveal;
- explain/voice answer;
- reconstruction/order;
- debugging/application prompt;
- compare answer vs source;
- continue reading.

### Reconstruction

- draggable/orderable steps;
- current attempt feedback;
- progressive **green check inside the step circle** for confirmed-correct positions;
- reset / submit / continue;
- do not reveal all remaining answers.

### Adaptive feedback (future-ready)

- You got / You missed / You mixed up / Source;
- concise misconception recovery;
- smaller follow-up question;
- exact source jump.

### Trails

- trail list;
- trail detail;
- ordered source-linked stops;
- continue trail;
- add/reorder/remove stop;
- future source-only intelligent suggestion.

### Connected passages

- one source → related passage;
- compare two exact sources;
- back-navigation continuity.

### Progress/session complete

- meaningful current learning movement;
- difficult items / continue reading;
- optional emotional completion states;
- no analytics dashboard.

### Settings

- Reading;
- Voice;
- local/on-device intelligence availability where appropriate;
- privacy/data ownership;
- library/storage/backup;
- emotional check-in settings.

## Visual acceptance

- no handwritten/script typography anywhere;
- no generic inspirational taglines;
- actual Leu content, not random playlist/aurora imagery;
- 44pt touch targets;
- Dynamic Type sanity;
- VoiceOver reading order;
- no clipped text on smallest supported iPhone;
- coherent design tokens across every screen;
- source provenance remains legible;
- reading page remains calmer than study controls;
- screenshots of all primary flows from the actual simulator build.
