## `night-field-03-recall-compare.png`

These are the strongest approved Claude visual direction references. Use them as a quality/taste north star, not as a requirement to keep the whole app dark or to copy pixels.

What the user likes here:

- strong hierarchy;
- compact information architecture;
- bold but controlled accent colors;
- source/learning state made visual rather than dashboarded;
- product-specific interaction language;
- seriousness without corporate/SaaS aesthetics.

## `reconstruction-green-check-guidance.png`

This is a current HTTP Caching reconstruction screen. The user has explicitly locked a future interaction refinement: when a step is confirmed correct, put a **green check inside its corresponding circle/step indicator**. Do not reveal the rest of the solution.

## Never reproduce

- handwritten/script/scribble text;
- generic motivational phrases;
- random auroras/playlists/landscape cards;
- generic AI neon/glass styling.
